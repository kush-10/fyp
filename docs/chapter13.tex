\chapter{Future Work}

{\small
This chapter prioritizes follow-up work by impact on the limitations in
Table~\ref{tab:limitations-impact-mitigation}. Items that strengthen quantitative
claims and artifact auditability come first, followed by scope expansion,
deployment readiness, negative-path assurance, and formal depth.

\begin{enumerate}
\setlength{\itemsep}{2pt}
\setlength{\parskip}{0pt}
\item \textbf{Extend commit-locked multi-trial coverage to all supporting targets.}
Rerun older supporting targets, including the unoptimised LowMC baseline and AES
backend variants, under the same clean-tree \(N=5\) policy as the headline runs.
The output should include variability bands, outlier notes, and regenerated
figures from one locked commit, directly mitigating mixed-provenance support
snapshots.

\item \textbf{Add per-target commit hashes to harness artifacts.}
Embed git revision metadata and dirty-tree status in every trial and aggregate
JSON record. This removes forensic ambiguity when results are rerun months later
and prevents a successful dirty-tree run from being mistaken for a clean release
artifact.

\item \textbf{Execute explicit AES backend feature-flag benchmarks.}
Run a strict \texttt{sbox-table} versus \texttt{sbox-logic} study under repeated
trials. This resolves whether the AES optimisation workspace gives measurable
zkVM value rather than relying on the current single-trial backend snapshot.

\item \textbf{Expand cross-zkVM replication.}
Port the same workload contract to at least one additional zkVM while preserving
input sizes, transcript framing, and benchmark IDs as closely as possible. This
tests whether the AES/LowMC ranking is RISC-Zero-specific or more general.

\item \textbf{Extend transport-layer authentication.}
Add signature-based sender binding for proof artifacts, with replay controls and
session identifiers so old valid receipts cannot be presented as fresh protocol
messages. This closes the current gap between data authenticity and sender
identity.

\item \textbf{Add negative-path authenticated-mode tests.}
Turn the design-level failure analysis into regression coverage by testing AAD,
IV, ciphertext, tag, key, and image-ID mismatches. These tests should fail closed
as code, framing, or guest images evolve.

\item \textbf{Tighten the security argument into a fuller reduction chain.}
Expand the Chapter 9 game sketch into theorem-level reductions, separating
confidentiality terms from integrity, soundness, and replay assumptions. This
raises the assurance story from structured argument to more formal cryptographic
reasoning.
\end{enumerate}

Items 1 and 2 have the highest immediate effect on report confidence because they
improve statistical strength and auditability. Items 3 and 4 determine how far the
findings generalize. Items 5 to 7 improve deployment readiness, executable
assurance, and formal review depth.
}
